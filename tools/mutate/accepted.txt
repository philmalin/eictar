# Mutants that make mutate does not count (doc/design.md 13.5): no test can
# find them, or no test of this run can.
#
# Each entry is the name that make mutate prints for the mutant, then one or
# more indented lines with the reason. An entry that the tests find, or that
# names no mutant, fails the run.
#
# Four kinds of reason are accepted:
# - Equivalent: the change cannot change what eictar does.
# - Too costly: a test needs more memory than a test can use. Each such entry
#   names the check that stops the same input before it gets there.
# - Needs root: only root can run the code, and make mutate does not run as
#   root. Each such entry names the test that the CI job as root runs.
# - Another platform: the code runs only on a platform where make mutate does
#   not run. Each such entry names the platforms.
